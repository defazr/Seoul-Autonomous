## 0. 부탁하는 역할

당신은 Google AdSense 심사 경험이 많은 외부 검토자입니다. 코드가 아니라 **판단**을 부탁합니다. 아래 자료만 보고(사이트는 아직 로컬에 있어 접속 불가) 다음 네 가지에 답해 주세요.

1. "가치 없는 콘텐츠(low value content)" 판정이 **아직 남을 가능성이 큰 곳**은 어디이고, 배포 전에 손댈 우선순위는 무엇인가.
2. **정류장 페이지 14개**(아래 §4-②)를 어떻게 할지 A/B/C 중 추천과 이유.
3. **재신청 시점**: 배포 직후 vs 색인 안정 후 몇 주 — 어느 쪽, 왜.
4. 우리가 **놓친 정책·신뢰 요건**이 있으면 구체적으로.

출력 형식: 요약 5줄 → BLOCK(재신청 전 반드시) → FIX(권장) → NOTE → 질문 1~4 답(각각 근거 1~2줄). 추측이면 추측이라고 표시해 주세요.

## 4. 미해결·결정 필요 (핵심 질문 대상)

① **404 셸** — 없는 주소의 응답이 상태 404·noindex 는 정상이지만 서버 HTML 본문이 비어 있고(프레임워크가 클라이언트 렌더용 문서를 내보냄) 헤더·푸터가 없음. 수정 조사 중. 심사에 얼마나 중요하다고 보십니까?

② **정류장 페이지 14개(7곳 × 한/영)** — 내용: 정류장 이름·정류소 번호·지나는 자율주행 노선·정차 순서·이전/다음 정류장(1곳은 요청 시 도착정보 카드). 사람이 쓴 문장 0, 공통 템플릿 비율 62~70%, 같은 이름의 양방향 쌍 유사도 0.57~0.77. 내부 정책 문서가 "저가치 페이지는 noindex 로 숨기지 않고 애초에 만들지 않는다 · 생성된 정류장 페이지 = 전부 색인·사이트맵 포함"으로 잠겨 있어 CC 가 임의로 바꾸지 못함.
   A. 계약 유지, 현재 상태로 심사 / B. 양방향 2개를 한 페이지로 합치고 출구·방면 설명 한 단락씩 사람 문장 추가(확인 가능한 사실만) / C. 보강 전까지 사이트맵 제외 + noindex(정책 예외)

③ **자율주행 노선 22페이지의 요금 고지** — "요금은 탑승 전 공식 안내에서 확인하세요. 기준일 이후 바뀌었을 수 있어 금액을 표시하지 않습니다"(확인 기준일 2026-05-01, 5.5개월 전). 재확인은 운영자가 직접 해야 함. 심사 관점에서 "방치된 섹션"으로 읽힐 위험이 어느 정도인가.

④ **운영자 표기** — 소개 페이지에 "다파라코프가 서울에서 독립적으로 운영" + 메일. 이름·사진·이력 없음. E-E-A-T 관점에서 필요한 최소치는 무엇인가.

⑤ **기본 로케일이 영어(/ → /en)** — 실제 수요는 한국어. 심사 계정이 한국이라면 첫 화면이 영어인 것이 불리한가.
