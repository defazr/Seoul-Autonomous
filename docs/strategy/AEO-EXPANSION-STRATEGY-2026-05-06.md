# Seoul Autonomous — AEO 확장 전략 메모
작성일: 2026-05-06
상태: 병행 전략 논의 완료
역할: Round 2 디자인 작업 이후 AEO/페이지 확장/도메인 판단 기준

---

## 1. 핵심 결론

Seoul Autonomous는 단순히 45페이지짜리 배포 가능한 웹사이트로 끝내지 않는다.

목표는:
- 실제 사용자가 검색해서 들어오는 정보 사이트
- AI 검색/네이버 AI 검색탭/AEO에 인용되기 쉬운 구조
- 서울 자율주행버스·로보택시 주제에서 충분한 깊이를 가진 사이트
- 단, 불필요한 페이지 양산은 하지 않는 사이트

현재 45페이지는 기반으로는 충분하지만, 네이버/AEO 관점에서 주제 권위와 질문 커버리지는 더 보강할 여지가 있다.

---

## 2. 페이지 확장 원칙

페이지는 늘릴 수 있다. 목표는 60~70페이지 수준까지 확장 가능성을 열어둔다.

단, 페이지 수만 채우는 방식은 금지한다.

금지:
- Route Detail과 거의 같은 내용을 반복하는 노선별 가이드 양산
- Unknown 데이터를 추정으로 채우기
- 관광 정보/맛집/후기/블로그 기반 콘텐츠 삽입
- 공식 출처 없는 주변 가볼만한 곳 추가
- routes.json 구조를 사전 합의 없이 확장
- SEO/AEO를 핑계로 얇은 페이지 양산

허용 방향:
- routes.json 기반 확정 정보 재구성
- 사용자가 실제로 묻는 질문에 직접 답하는 페이지
- AI가 인용하기 쉬운 Q&A/가이드 구조
- Unknown은 숨기지 않고 확인 행동으로 연결
- 공식 출처가 있는 경우에만 관광/주변 정보 검토

## 3. AEO 질문 유형 분류

### 유형 A — 노선 특정 질문
Route Detail이 흡수해야 한다.

예:
- 청계천 자율주행버스 어디서 타나요
- Cheongwadae autonomous bus stops
- 새벽동행 A160 운행시간
- 이 노선 요금은 얼마인가요
- 예약이 필요한가요
- 이 노선 정보는 언제 확인됐나요

### 유형 B — 일반 이용 질문
FAQ / How to Ride / Route Detail 하단 요약이 흡수한다.

예:
- 서울 자율주행버스 타는 법
- How to ride autonomous bus in Seoul
- 외국인도 이용할 수 있나요
- 탑승 전 무엇을 확인해야 하나요

### 유형 C — 비교/탐색 질문
현재 가장 큰 공백이다. 별도 페이지 후보가 될 수 있다.

예:
- 새벽에 탈 수 있는 서울 자율주행버스
- 강남에서 탈 수 있는 자율주행 서비스
- 청계천 자율주행버스 안내
- 서울 로보택시 이용 안내
- 외국인 관광객을 위한 서울 자율주행버스 이용 가이드
- 버스형과 로보택시형 차이

### 유형 D — 신뢰/안전 질문
Data Source / FAQ / 향후 안전 페이지 후보로 다룬다.

예:
- 이 정보는 정확한가요
- 실시간 도착정보가 있나요
- 서울 자율주행버스 안전한가요

안전 페이지는 1차 공식 출처 없으면 보류한다.

## 4. Route Detail 재설계 방향

Round 2 A에서 Route Detail을 단순 데이터 나열형에서 질문 대응형 상세 페이지로 강화한다.

핵심:
- Route Detail이 유형 A 질문을 최대한 흡수한다.
- 일부 유형 B 질문은 짧게 요약하고 FAQ / How to Ride로 연결한다.
- 유형 C는 Route Detail에 억지로 넣지 않고 별도 페이지 후보로 분리한다.

Route Detail에 흡수할 질문 후보:
1. 이 노선은 어디서 타나요?
2. 이 노선은 어느 정류장을 지나나요?
3. 첫 정류장과 마지막 정류장은 어디인가요?
4. 첫차와 막차 시간은 어떻게 확인하나요?
5. 이 노선은 평일만 운행하나요?
6. 배차 간격은 확인되어 있나요?
7. 요금은 확인되어 있나요?
8. 예약이 필요한가요?
9. 별도 앱이 필요한가요?
10. 카카오맵에서 이 노선을 어떻게 다시 확인하나요?
11. 이 노선 정보는 언제 마지막으로 확인됐나요?
12. 이 노선은 실시간 도착정보를 제공하나요?
13. 이 노선을 이용하기 전에 무엇을 확인해야 하나요?
14. 외국인 방문객이 이 노선을 이용할 때 주의할 점은 무엇인가요?
15. 이 노선과 비슷한 다른 자율주행 노선은 어디서 볼 수 있나요?

실제 Route Detail에는 이 중 8~10개 정도를 흡수하고, 나머지는 FAQ / Routes / 향후 그룹 페이지로 연결한다.

## 5. Unknown 필드 처리 원칙

Unknown이 많다고 질문을 빼지 않는다.

사용자 의도가 강한 질문은 남긴다.  
다만 답변은 단정하지 않고 확인 행동으로 연결한다.

예:
- 요금이 Unknown이면: 요금 정보는 아직 확인되지 않았습니다. 탑승 전 카카오맵 또는 공식 안내에서 확인하세요.
- 예약 여부가 Unknown이면: 예약 필요 여부는 아직 확인되지 않았습니다. 탑승 전 운영사 또는 공식 안내를 확인하세요.
- 실시간 정보는 제공하지 않음: 이 사이트는 실시간 도착정보를 제공하지 않습니다. 탑승 전 카카오맵 또는 공식 안내를 확인하세요.

Unknown은 품질 저하가 아니라 신뢰 정책의 일부로 보여준다.

## 6. 데이터 구조 결론

### 1단계 — 지금은 새 데이터 파일을 만들지 않는다

Route Detail 1차 AEO 강화는 다음만 사용한다:
- routes.json 필드
- 기존 FAQ 원칙
- Data Source 문구
- How to Ride 문구
- 공통 i18n 템플릿

즉:
- routeGuides 파일 도입 보류
- content 디렉토리 도입 보류
- routes.json에 가이드 문장 추가 보류
- i18n에 장문 콘텐츠 대량 추가 보류

### 2단계 — 필요할 때만 routeGuides 검토

Route Detail 템플릿으로 부족한 노선별 고유 설명이 확인될 때만 routeGuides를 검토한다.

예:
- 특정 노선의 탑승 위치 설명
- 특정 노선의 관광객 유의사항
- 특정 노선의 주변 안내

단, 공식 출처 또는 확정 데이터가 있을 때만 가능하다.

### 3단계 — 별도 페이지 확장 시 content 구조 검토

지역/시간대/관광객/유형별 페이지가 필요하다고 확정되면 그때 content 구조를 검토한다.

예:
- web/data/content/areas
- web/data/content/time-groups
- web/data/content/guides

이 단계는 AEO 확장 audit 이후에만 진행한다.

## 7. 60~70페이지 확장 후보

Round 2 이후 검토할 수 있는 페이지 후보:

### 시간대별
- 새벽에 탈 수 있는 서울 자율주행버스
- Late-night autonomous bus routes in Seoul

### 지역별
- 청계천 자율주행버스 안내
- 강남 로보택시 안내
- 상암 자율주행버스 안내
- 청와대 자율주행버스 안내

### 이용자 유형별
- 외국인 관광객을 위한 서울 자율주행버스 안내
- 서울 여행 중 자율주행버스 타는 법

### 노선 유형별
- 서울 자율주행버스 노선 모음
- 서울 로보택시 이용 안내
- 버스형 vs 로보택시형 차이

### 확인/주의 페이지
- 서울 자율주행버스 탑승 전 확인할 것
- 실시간 정보가 없는 이유와 확인 방법

이 후보 중 10개만 en/ko로 만들어도 20페이지가 추가된다.  
현재 45페이지에서 65페이지 전후까지 확장 가능하다.

단, 각 페이지는 다음 기준을 통과해야 한다:
- 실제 검색 가능성
- 외국인 방문객 도움
- AI 인용 가능성
- routes.json 또는 공식 출처 기반
- 새 추정 없이 작성 가능
- 유지보수 부담이 낮음
- 기존 Route Detail / FAQ / How to Ride와 중복되지 않음

## 8. 관광 정보 / 가볼만한 곳 처리

관광 정보는 방향성은 좋지만 지금 당장 도입하지 않는다.

조건:
- Visit Seoul
- 서울시 공식 관광/시설 페이지
- 공식 시설 웹사이트
- 기타 1차 공식 출처

금지:
- 맛집
- 후기
- 블로그
- 나무위키
- 커뮤니티
- 거리/도보 시간 추정
- 근처라는 기준 없는 장소 나열

관광 정보는 Route Detail 재설계와 동시에 진행하지 않는다.  
AEO 확장 audit 이후, 공식 출처 확보 가능성이 확인될 때만 별도 라운드로 검토한다.

## 9. 도메인 선택 초안

도메인 결정은 Round 2 완료 후 별도 audit에서 한다.

비교 대상:
1. autonomous.fazr.co.kr 유지
2. 새 도메인 사용
3. 임시 하위도메인 후 새 도메인 이전

현재 경향:
- 단기 AdSense / 빠른 배포: autonomous.fazr.co.kr 유리
- 장기 SEO/AEO 신뢰 / fazr.co.kr 리스크 분리: 새 도메인 유리
- 임시 후 이전: 두 번 일할 가능성이 높고, 301 / GSC / 네이버 / AI 인용 URL 리스크가 있어 신중

새 도메인 후보에서 seoulav.com은 제외 권고.  
AV 약어가 다른 의미로 읽힐 수 있어 브랜드 리스크가 있음.

하이픈 도메인은 SEO 불리라고 단정하지 않는다.  
다만 기억성/입력 편의성 측면에서 비선호라고 본다.

도메인 최종 결정은 Round 2 후 진행한다.
