# GPT 외부 검토 결과 (2026-10-16 · 브리프 GPT-BRIEF-20261016.md 에 대한 답 · 포그린이 전달한 원문)

포그린 결정: CC 이견 2건 동의 · 정류장 14페이지 = **B** (양방향 통합 + 사람 문장 보강).

## 요약 5줄
- 새 구조(홈 경로탐색·N노선 5·허브 3·출처/업데이트/제보)는 4차 때보다 확실히 강함 — "데이터 나열"에서 "서비스"로 이동한 증거.
- 가장 큰 잔존 위험 = 정류장 14페이지(사람 문장 0 · 템플릿 62~70% · 양방향 쌍 유사도 높음).
- Google Publisher Policies 는 저가치뿐 아니라 사람 검토·큐레이션 없는 자동 생성 콘텐츠에 광고를 붙이는 형태를 문제 삼음.
- A ❌ / B ✅ / C △(noindex 는 Search 색인 제어일 뿐 AdSense 심사에서 페이지 존재를 없애지 못함).
- 5차 신청 = 배포 직후가 아니라 안정 배포 후 약 4주(Google 규칙이 아니라 "4연속 거절 후 대규모 정체성 변경" 상황에 대한 운영 판단).

## BLOCK — 5차 전에 반드시
1. 정류장 14개 → B. 7개 실제 장소 기준으로 양방향을 한 페이지에 합치고 방향 A/B 를 분명히 분리. 핵심은 "사람 문장 한 단락"이 아니라 각 페이지가 다음에 답하는 것: 어느 방향 승강장인가 · 정류소 번호 · 어느 노선을 어느 방향으로 타는가 · 반대편 정류장과 무엇이 다른가 · 이전·다음 정류장 · 환승·위치 판단에서 알아야 할 것. 데이터 행을 문장으로 풀어쓰는 게 아니라 "방향 선택 문제를 해결하는 페이지".
2. "확인 필요"가 본문 절반인 짧은 업데이트 글 2개(05-09)와 목록형 노선 그룹 페이지 2개(early-morning·late-night)를 그대로 두고 재신청하지 말 것 — 완결된 정보 페이지로 만들거나 공개 상태 재검토(삭제하라는 뜻 아님).
3. 자율주행 22페이지의 2026-05-01 기준 정보는 실제 재검증 한 번 — 금액을 다시 넣으라는 뜻이 아니라 최신 공식 자료 확인 후 확인 기준일 자체를 갱신.

## FIX — 강력 권장
- 404 셸은 low-value 주범 아님(404 상태·noindex 정상이면 5차를 막지 않음). 단, 승인 후 Auto ads 를 쓰면 404·오류·빈 화면에 광고가 뜨지 않게 할 것.
- 운영자 표기는 최소선 통과. 실명·사진·경력은 필수 아님. "누가/어떻게 관리하는가"만 분명히 — 예: "다파라코프가 서울시 공공데이터와 공식 공지를 바탕으로 직접 검증·가공하여 운영하며, 오류 제보를 확인해 수정합니다."
- 기본 / → /en 은 정책 BLOCK 아님. 제품적으로는 Accept-Language 기반 또는 /ko 우선에 한 표(심사자 계정 국가가 불이익이라는 근거는 없음).

## NOTE
- 사진 부족은 문제 아님(고유 가치 = 노선도·경로계산·정류소 번호·방향·조회 도구). stock photo 는 해결책 아님. 댓글·회원·장문 블로그도 필수 아님.
- 승인 후 EEA·영국·스위스 개인 맞춤 광고 시 Google 인증 CMP/TCF 요건 확인(승인 후 항목).

## 질문별 답
1. low-value 잔존 순위: ① 정류장 14 → ② 짧은 업데이트/목록형 그룹 → ③ 오래된 기준일의 자율주행 콘텐츠. N노선·허브·홈 경로탐색은 걱정 대상이 아니라 고유 가치 축.
2. B. 핵심은 14→7 숫자 감소가 아니라 "한 장소를 한 페이지에서 완결적으로 이해".
3. 배포 직후 NO, 약 4주 후. 배포 후 Googlebot 접근·실제 유입·경로탐색 사용·오류/이탈·데이터 갱신·회귀를 본 뒤. 79 URL 전부 색인될 때까지 기다릴 필요는 없음.
4. 놓친 요소: ① 자동 생성 페이지의 사람 검토·큐레이션 ② freshness("언제 확인됐고 누가 어떻게 고치는가") ③ 404 에 광고 안 뜨게 ④ 승인 후 CMP.
