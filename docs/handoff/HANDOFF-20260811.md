## E. 결함 아님으로 실증 종결한 관찰 2건

**① googleads 403 (1건)**
`googleads.g.doubleclick.net/pagead/ads?client=ca-pub-7976139023602789` → 403.
승인 전 계정이라 광고 요청이 거절되는 정상 동작이며 Round 26 배포 QA 기준선과 동일.
오히려 **AdSense 스크립트가 올바른 publisher ID로 실제 발화 중**이라는 방증이다.

**② `?_rsc=` prefetch ERR_ABORTED**
클라이언트 prefetch 취소. 동일 URL을 서버에 직접 요청하면 `200 text/x-component` 정상 응답(3건 표본 실측).

## F. 검사 도구 결함 2건 — 실제 결함이 아니라 도구 문제였다

이번에도 "0 또는 이상 수치가 나오면 도구부터 의심" 원칙이 유효했다.

```
① zsh 워드 분할 미적용으로 첫 URL 루프가 통째로 헛돌음
   → 목록 파일 + while read 로 교체 후 재실행. 0건 판정으로 넘기지 않음
② AdSense 스크립트 "페이지당 2회" 초기 수치
   → 실물 태그 재검증 결과 script 태그는 1개.
     나머지 1회는 Next.js RSC 페이로드 내 문자열. 중복 삽입 아님
```

추가 적용한 안전선: SSR one-line HTML에 `grep -c` 금지 / 개수는 findall·`grep -o | wc -l` /
축약 SHA와 full SHA 혼용 금지 / `set +e` 로 셸 조기 종료 격리 / 추정 URL 검사 금지.

**신규 교훈: zsh는 unquoted 변수를 워드 분할하지 않는다.** bash 습관대로 `for u in $URLS` 를 쓰면
루프가 1회만 돌면서 전체 문자열을 한 URL로 취급한다. 다건 순회는 목록 파일 + `while IFS= read -r` 로 한다.

배포 8일차라 기존 기준(2~3주)의 하한(08-17)에도 미달함을 근거로 **08-17 이후를 권고**했다.
포그린은 GSC 자료(valid URL 다수, 핵심 페이지 최근 재크롤 확인)를 근거로 **즉시 재신청**을 결정했고,
실제 재크롤 날짜가 달력 2주보다 나은 근거라는 판단이었다. 결정권은 포그린에게 있으므로 그대로 실행됐다.
