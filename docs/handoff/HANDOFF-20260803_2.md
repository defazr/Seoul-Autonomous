## B. 구현 계약 (커밋 `abb0ba7`)

- `web/app/[locale]/night-bus-map/NightBusMap.tsx` **1개 파일**, `+120 / −5`
- 데스크톱: `.obStage` React `onDoubleClick`, `e.button === 0`, 터치 파생 합성 dblclick 700ms 억제, 인라인 SVG target guard(공용 svgRef 미사용 — `:scope > svg`)
- 터치: React Pointer Event 4종, **`pointerType === 'touch'`만 인정**(폭·isMobile 분기 비의존), 최대 간격 **300ms** · 두 탭 거리 **40px** · 탭 이동 취소 **8px**, 두 번째 손가락·핀치·스와이프·`pointercancel` 전부 후보 취소, 터치 Pointer handler `preventDefault()` **0**
- **공통 동기 잠금 ref**(`fsOpenLockRef`) — 버튼·마우스·터치가 동일 진입 게이트(`beginFullscreenEntry`) 사용, 더블탭은 다음 task 예약 진입(합성 이벤트 연쇄 차단)
- **인라인 기존 더블탭 확대 binding은 전체화면 진입으로 재배정**(포그린 확정). 인라인 핀치·팬 유지, 전체화면 내부 더블탭 확대(`onFsDoubleClick`) 유지
