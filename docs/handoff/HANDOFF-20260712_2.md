## 사용자 확인 후 변경된 결정 — verificationNote 전면 삭제

- 페이지 상단에서 사이트 신뢰도를 스스로 떨어뜨리는 인상을 줌
- 기존 FAQ와 역할 중복
- 실제 정보 카드에 요금·운영사·예약 필드가 존재하지 않아 UI 설명("—로 표시")도 부정확했음
- 부정 안내를 22페이지에 반복할 필요가 없음

최종 노선 안내 = H2 + overview + useCase만. 미확인 정보 안내는 기존 FAQ가 담당.
