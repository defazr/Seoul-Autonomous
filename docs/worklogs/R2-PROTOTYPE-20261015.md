## 4.1 지도 전략 — 포그린 CorelDRAW 노선도와 지리 지도의 역할 분리 (2026-10-15 포그린 질문 후 추가)

현 사이트 `/ko/night-bus-map` 의 지도는 포그린이 CorelDRAW 로 그린 노선도다. 2026-06-10 에 그 작도를 좌표 배열로 변환해
`night-bus-data.ts`(역 노드 115 · 노선 폴리라인 15 · 한강 path · 노선 색 · 노선별 주요 역 목록, **읽기 전용**)에 넣었고,
`NightBusMap.tsx`(1,023줄)가 SVG 로 그린다. 검색(초성) · 노선 선택 강조 · 직통→1회 환승→2회 환승 탐색 · 공유 환승역 표시 ·
줌/팬 · 전체화면(더블탭) · PNG 저장 · 네이버 길찾기 링크가 들어 있다. **실사용 트래픽의 90% 가 이 페이지에서 나온다.**

시안 v2 의 지도는 이것이 **아니다**. 서울시 공식 정류소 좌표 2,078개를 그대로 이은 지리 선도(캔버스)다.
"내 위치 → 가장 가까운 정류소 · 차량 위치 · 정류소 번호" 가 실좌표를 필요로 해서 그렸다.

기존 노선도 로직 검토 결과(2026-10-15, 코드 읽기):
```
탐색     직통(주요 역 목록 두 곳 포함 · 역 인덱스 차 최소) → 1회 환승(두 노선 공통 역 · 홉 합 최소) → 2회 환승 폴백 → 없음
장점     명확 · 빠름 · 환승역을 눈으로 확인시키는 UI(공유 환승역 바 · leg 숨기기) · 전체화면·PNG 등 완성도 높음
한계     ① 노드가 주요 역 115개뿐 — 실제 정류소 1,483개 중 나머지는 탐색 불가  ② 정류소 번호(ARS)·방면 없음
         ③ "홉" = 주요 역 간 수이지 실제 정류장 수가 아님  ④ 환승은 주요 역에서만 판정  ⑤ 도착정보 없음
```

**결정: 노선도는 버리지 않고 승격한다. 두 지도는 역할이 다르다.**
```
포그린 노선도(도식)   = 사이트의 정본 "노선도". /ko/night-bus-map 유지 · 홈 히어로 배경 후보 · 공유 이미지 원본
                       승격: 115 역 노드를 ARS 정류소 그룹에 매핑하는 파생 파일(작도 데이터는 무수정) → 역 카드에 정류소 번호·방면·(R4) 도착 표시
                       탐색은 R1 전정류장 엔진으로 교체 — 그림은 그대로, 답(정류장 수·방면·환승 정류소)만 정확해짐
지리 지도(실좌표)     = 위치가 필요한 곳에만: 내 위치 근처 정류소 · 노선 상세의 실제 경로 · 차량 위치(R4) · 허브 지도
```
