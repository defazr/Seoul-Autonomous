# 사실 검수 결과

판정 기준은 `night-bus-routes.json`의 실제 정류장 순서와 `official`, 그리고 개략 노선도인 `ROUTE_MEMBER`입니다. 비교 표현은 `category: "owl"`인 N계열 14개 노선을 기준으로 확인했습니다.

## N61

- **PASS — summary 경유 순서**
  - 양천공영차고지 → 개봉역 → 신림역 → 서울대입구역 → 사당 → 교대 → 강남 → 역삼 → 선릉 → 삼성 → 건대입구 → 군자 → 중화 → 태릉입구 → 노원·상계 순서가 실제 정류장 및 `ROUTE_MEMBER`와 일치합니다.
  - `남부터미널역` 등이 생략됐지만 순서 왜곡은 아닙니다.

- **PASS — 거리·대수 비교**
  - 공식값은 거리 `90.0km`, 운행 대수 `16대`입니다.
  - 14개 노선 중 거리와 대수가 모두 단독 최댓값이므로 “가장 크다”는 표현이 맞습니다.

- **PASS — areas**
  - `강남`, `건대`, `노원` 모두 실제 정류장 또는 `ROUTE_MEMBER`에 있습니다.

- **PASS — 강남역 정류소 복수**
  - 실제로 `강남역1번출구.역삼세무서`, `강남역8번출구`, `강남역9번출구`, `강남역12번출구` 등이 방면별로 존재합니다.

- **PASS — 노원 이후 노선도 미표시 구간**
  - `ROUTE_MEMBER`는 노원역에서 끝나지만 실제 목록에는 상계주공단지와 상계동 일대 정류장이 더 있습니다.

- **FIX — 막차 임박 시 운행 판단**
  - “막차 가까운 시간에는 다음 차가 없을 수 있습니다”는 정적 데이터만으로 특정 시점의 다음 차량 존재 여부를 확인할 수 없고, 실시간 안내처럼 읽힙니다.
  - 교체 문장:
    > 공식 배차간격은 10~30분이며, 막차는 04:10 기점 출발입니다.

- **PASS — useCases**
  - 제시된 세 OD 조합 모두 실제 노선으로 직접 연결됩니다. 소요 시간·혼잡·편의 우열 주장은 없습니다.

## N15

- **PASS — summary 경유 순서**
  - 우이동 → 쌍문 → 수유 → 길음 → 성신여대입구 → 동대문 → 종로 → 을지로입구 → 서울역 → 삼각지 → 신용산 → 노량진 → 장승배기 → 신림 → 서울대입구 → 사당 → 남태령 순서가 실제 정류장 및 `ROUTE_MEMBER`와 일치합니다.

- **PASS — areas**
  - `사당`, `서울역`, `동대문` 모두 실제 정류장에 있습니다.

- **PASS — 배차·첫차·막차**
  - 공식값 `15~30분`, `23:30`, `03:30`과 일치합니다.

- **PASS — 을지로입구 편도 경유**
  - `을지로입구역.광교`는 우이동→남태령 방면에만 있습니다.
  - 반대 방면은 명동·우리은행종로지점을 거쳐 종로로 진입하므로 “방면별 정류장 목록이 서로 다르다”는 설명도 맞습니다.

- **FIX — 남태령 노선도 미표시 주장**
  - `ROUTE_MEMBER`에 `남태령역`이 있고 `ROUTE_POLY`에도 해당 노드가 포함되어 있습니다. 실제 정류장 목록에도 양방향 남태령역이 있습니다.
  - 교체 문장:
    > 남태령역은 회차 구간에 있어 정류장 번호가 방면별로 다릅니다.

- **NOTE — 중간 정류장 통과 시각**
  - “중간 정류장은 더 늦게 지나갑니다”는 논리적으로 맞지만, 이 데이터에는 정류장별 예정 시각이 없습니다. 정확한 통과 시각을 제공하는 표현으로 확대하면 안 됩니다.
  - 더 엄밀한 표현:
    > 첫차 23:30과 막차 03:30은 기점 출발 시각이며, 정류장별 통과 시각은 이 데이터에 포함되어 있지 않습니다.

- **PASS — useCases**
  - 세 OD 조합 모두 실제 정류장 순서상 연결됩니다.

## N31

- **PASS — summary 경유 순서**
  - 강동공영차고지 → 고덕 → 암사 → 천호 → 강동구청 → 잠실 → 삼성 → 선릉 → 역삼 → 강남 → 논현 → 신사 → 한남 → 이태원 → 도심 → 혜화 → 성신여대입구 → 정릉·국민대 순서는 맞습니다.
  - `을지로입구 → 종각·종로 → 동대문`은 `ROUTE_MEMBER`의 국민대→강동 방향 순서를 역으로 기술한 것입니다.
  - 다만 실제 `stops`에는 이름에 “동대문”이 들어간 정류장이 없습니다. `동대문역`은 개략 노선도의 주요 노드로만 표시됩니다.

- **PASS — areas**
  - `강남`, `잠실`, `천호` 모두 실제 정류장에 있습니다.

- **PASS — “배차가 긴 편”**
  - 공식값은 `35~40분`입니다.
  - 14개 노선 중 최대 배차간격 40분은 N72와 공동 최댓값이며, 최소 배차간격 35분도 N73과 공동 최댓값입니다. 따라서 “긴 편”은 충분히 뒷받침됩니다.

- **FIX — 한 대를 놓친 뒤의 실제 대기시간**
  - “한 대를 놓치면 그만큼 기다립니다”는 실제 운행 간격이 항상 공식 범위와 동일하다는 전제가 필요하므로 정적 데이터로 확인할 수 없습니다.
  - 교체 문장:
    > 공식 배차간격은 35~40분으로 14개 노선 중 긴 편입니다.

- **FIX — 을지로입구·동대문 정류장의 방면 차이**
  - `을지로입구역.광교`는 국민대→강동 방면에만 있어 편도 경유 주장이 맞습니다.
  - 반면 `stops`에는 어느 방면에도 “동대문” 명칭 정류장이 없으므로 “동대문 쪽 정류장이 방면별로 다르다”는 문장은 확인할 수 없습니다.
  - 교체 문장:
    > 도심 구간의 을지로입구역.광교 정류장은 국민대에서 강동으로 가는 방면에만 있습니다. 반대 방면은 명동에서 종로로 바로 이어집니다.

- **PASS — 첫차·막차**
  - 공식값 `23:30`, `03:50`과 일치합니다.

- **PASS — useCases**
  - 세 OD 조합 모두 실제 노선으로 연결됩니다.
  - 단, `동대문`은 실제 동명 정류장보다는 개략 노선도상의 주요 지점이라는 점을 유의해야 합니다.

# 도심 편도 순환 주장 종합

- **N15:** `을지로입구역.광교`는 우이동→남태령 방면에만 있음 — **PASS**
- **N31:** `을지로입구역.광교`는 국민대→강동 방면에만 있음 — **PASS**
- **N31 동대문:** “동대문” 명칭 정류장은 양방향 모두 없음 — 기존 문장 중 동대문 부분은 **FIX**
- **시청 계열:** N15와 N31 정류장 목록에는 시청 명칭 정류장이 없음
- 따라서 편도 순환의 확실한 근거로 쓸 수 있는 지점은 두 노선 모두 `을지로입구역.광교`입니다.
