## 5. Round 26-C3 — 완료·커밋 `1682447`

### 5-1. FAQ q1 반환점 오류 해결

수정 전에는 ko가 `stops[0]`·`stops[마지막]`을, en이 `route.startPoint`·`route.endPoint`를 써서 **두 언어가 서로 다른 사실**을 말했다. 왕복형에서 ko는 같은 이름을 두 번 반복하고, en은 반환점을 종점으로 표시했다.

**해결**: `endPoint` 사용을 완전히 끊고 stop 배열 구조로만 3분기한다. 노선 id 하드코딩이나 상암A21 전용 예외는 쓰지 않는다.

```
첫·마지막 stopId 동일      2   cheonggye-a01, seodaemun-a01
이름 동일·stopId 다름      5   saebyeok-a160, saebyeok-a741, simya-a21, dongjak-a01, saebyeok-a504
첫·마지막 이름 다름        4   saebyeok-a148, dongdaemun-a01, sangam-a21, cheongwadae-a01
```

빈 stop 배열이거나 반환점이 1개가 아니면 즉시 throw한다(조용한 fallback 금지).

`dongdaemun-a01`의 회차 지점은 요약 레이블 "경희의료원"이 아니라 실제 정류장명 "경희대의료원.경희여중고"로 표기했다.

### 5-2. RouteContext 구조 확장

```
overview      노선이 연결하는 실제 이동 축과 권역
routePattern  stop 배열로 확인되는 운행 구조
keyStopIds    주요 정류장 3~5개 (stopId만 저장, 표시명은 서버가 해결)
useCase       어떤 이동에 참고할 수 있는지
```

`keyStopIds`는 ko/en 완전 동일하며, 표시명은 FAQ·노선 한눈에 보기와 **같은 resolver**를 쓴다. 한 페이지 안에서 같은 stopId가 다른 이름으로 나오지 않는다.

## 7. 이번 세션 교훈

1. **문서 수정 금지 라운드는 핸드오프 공백을 만든다.** C2E 지시서가 docs 수정 0을 강제해, `SESSION-HANDOFF.md`가 "QA 착수 전"에 멈춘 채 실제로는 커밋까지 끝난 상태가 됐다. 다음 세션이 문서만 믿었으면 끝난 작업을 다시 했을 것이다. → 문서 금지 라운드에서는 **금지 사실 자체를 어딘가에 남겨야** 한다.
2. **조사 라운드의 성공 기준은 채운 값의 수가 아니다.** 48셀 중 38셀이 미확인이지만, 각 셀에 조사 경로와 종료 사유가 붙어 있어 다음 라운드가 같은 검색을 반복하지 않는다.
3. **공식 문서가 스스로 유효기간을 예고하면 그 시점을 반드시 확인해야 한다.** "무료(하반기 유상 전환 예정)"를 무료로 기록했다면 4개 노선에서 틀린 값을 확정할 뻔했다.
4. **측정 방법이 결과를 좌우한다(재확인).** 닫힌 `<details>` 내부 행을 `offsetParent`로 재면 90개가 보이는 것처럼 나온다. Chrome이 `content-visibility:hidden`을 쓰기 때문이며, `checkVisibility({contentVisibilityAuto:true})`로 재야 닫힘 3 / 열림 87이 정확히 나온다.
5. **Codex는 웹 조사를 대신하지 않는다.** 조사자와 감사자가 같으면 §15 감사가 자기 채점이 된다.
6. **상대경로 스크립트가 범위 밖 파일을 고칠 수 있다.** 이 저장소는 루트에 React Native, `web/`에 Next.js가 있어 `data/routes.json`이 둘이다. cwd가 바뀐 줄 모르고 상대경로로 쓴 결과 루트 파일을 수정했다(즉시 원복). **스크립트는 절대경로로.**
7. **지적된 것만 고치면 같은 문제가 남는다.** C3.1에서 Codex가 지목한 표현만 고쳤더니 같은 성격의 표현이 열 곳 넘게 남아 C3.2에서 다시 잡았다. 지적을 받으면 **같은 유형을 전수 검사**해야 한다.
8. **비교 주장은 전 노선 대조 후에만.** "다른 노선과 달리 같은 승강장으로 돌아온다"가 틀렸다. 순환형은 청계A01·서대문A01 둘이다. 최종 시각 검수에서야 잡혔다.
