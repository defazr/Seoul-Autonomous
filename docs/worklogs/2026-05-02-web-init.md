**Date:** 2026-05-02

## Next.js Version Decision

**Selected: Next.js 16.2.4** (npm `latest` tag)

### Version landscape at time of decision

| Tag | Version |
|-----|---------|
| latest | 16.2.4 |
| canary | 16.3.0-canary.8 |
| next-15-3 | 15.3.9 |
| next-14 | 14.2.35 |

### Rationale

- `latest` npm tag = stable production channel. 16.2.4 is the current stable release.
- No beta/rc/canary — this is a full release.
- Includes React 19.2.4 (stable).
- App Router is the default and well-established.
- `next/font/google` includes Geist natively — no extra package needed.
- Turbopack is default for dev and build.
- Seoul Autonomous web is a static/SSG site with no complex API routes — minimal surface area for breaking changes.

### Breaking changes noted

- `AGENTS.md` and `CLAUDE.md` auto-generated by `create-next-app` (new in 16.x) — removed as unnecessary.
- Turbopack `root` config needed for monorepo structure (parent directory has its own package-lock.json).
- `params` in layouts/pages is now `Promise<>` (async) — noted for future dynamic routes.

## Design Token Migration

### tokens.ts changes from app version

- **Shadows:** Converted from RN format (`shadowColor/shadowOffset/shadowOpacity/shadowRadius/elevation`) to CSS `box-shadow` strings.
  - `sm: '0 1px 2px rgba(0, 0, 0, 0.4)'`
  - `md: '0 4px 16px rgba(0, 0, 0, 0.5)'`
  - `lg: '0 16px 48px rgba(0, 0, 0, 0.7)'`
  - `glow: '0 0 24px rgba(0, 212, 255, 0.32)'`
  - `inner` removed (was empty/unused in app)
- **All other tokens:** Identical to app version. No changes.

### CSS variables (globals.css)

68 CSS custom properties defined in `:root`:
- 5 background colors (`--color-bg-0` ~ `--color-bg-4`)
- 5 foreground colors (`--color-fg-1` ~ `--color-fg-5`)
- 3 border colors (`--color-border-1` ~ `--color-border-3`)
- 5 accent colors (`--color-accent`, `-hi`, `-lo`, `-glow`, `-faint`)
- 4 status colors (`--color-success`, `-warning`, `-danger`, `-info`)
- 14 spacing values (`--space-1` ~ `--space-10`, `-screen`, `-card`, `-card-gap`, `-section-gap`)
- 7 radius values (`--radius-xs` ~ `--radius-pill`)
- 4 shadow values (`--shadow-sm` ~ `--shadow-glow`)
- 3 font stacks (`--font-sans`, `--font-mono`, `--font-kr`)

## Font Setup

### Geist (applied)

- Loaded via `next/font/google` — `Geist` and `Geist_Mono`
- Injected as CSS variables: `--font-geist-sans`, `--font-geist-mono`
- Applied to `<html>` via className
- `--font-sans` in globals.css references `var(--font-geist-sans)` with Pretendard fallback

### Pretendard (NOT applied this round)

**Recommendation for next round:**

- **License:** SIL Open Font License 1.1 (free for commercial use)
- **Source:** https://github.com/orioncactus/pretendard
- **Files available:** App has `/assets/fonts/Pretendard-Regular.otf`, `Pretendard-Medium.otf`, `Pretendard-SemiBold.otf`
- **Recommended approach:** `next/font/local` with the 3 .otf files copied to `web/public/fonts/` or `web/assets/fonts/`
- **Alternative:** CDN (`cdn.jsdelivr.net/gh/orioncactus/pretendard`) — adds external dependency but avoids file duplication
- **Config:** Add to `lib/fonts.ts` as a separate export with `variable: '--font-pretendard'`
- **Font-family fallback** already set in globals.css: `Pretendard, -apple-system, BlinkMacSystemFont, sans-serif`
